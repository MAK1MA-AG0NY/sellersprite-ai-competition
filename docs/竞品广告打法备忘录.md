## 四、AFERIY（B0DRYQSXWV）的中小卖家对照样本

38 个广告组 / 27 个 campaign / 645 词，结构解读：

- **主力组**：198 词、连续投放 23 周（2026-03-08 至今）——长期稳定的核心转化组
- **测试组**：72 词的组只活了 5 周（2026-08 起）——正在测试的新词包
- **已关停组**：多个组 4~7 月投放后关闭——迭代速度快，淘汰 inefficient 组
- 对照 Jackery 单组 8,860 词：**大卖用自动组+海量词，中小卖家用精细分组+快迭代**。FOSSIBOT 现阶段应学 AFERIY 的结构（10 组以内、主力组长期稳定、每月淘汰弱组），而不是学 Jackery 的规模
