### 🎯 三个工具的核心定位

| 工具 | 数据来源 | 查询逻辑 | 核心作用 |
| :--- | :--- | :--- | :--- |
| **关键词挖掘** (`/v3/keyword-miner`) | 亚马逊真实用户搜索行为 | **词根 → 相关词** | **主动拓词**：从一个核心词根出发，批量挖掘相关长尾词，用于搭建Listing和广告词库 |
| **关键词反查** (`/v3/keyword-reverse`) | 卖家精灵抓取的前3页搜索结果 | **ASIN → 流量词** | **竞品流量结构分析**：查看竞品靠哪些自然词和广告词获取流量，了解其流量布局 |
| **出单词反查** (`/v2/aba/reverse/search`) | 亚马逊官方ABA报告（品牌分析） | **ASIN → 出单词** | **真实转化验证**：查看竞品在哪些词下**点击排名前三**，即真正带来订单的词，确定性最高 |

### 🔄 实战配合流程

#### 第一步：用「关键词挖掘」主动拓词
输入一个核心词根（如“wireless mouse”），利用“词根匹配（静态挖掘）”功能，批量挖掘相关长尾词。这一步的目的是**建立初始词库**，为后续分析提供素材。筛选时重点关注“相关度”排序，确保词与产品高度相关。

#### 第二步：用「关键词反查」拆解竞品流量结构
将上一步锁定的头部竞品ASIN输入，查看其**自然流量词**和**广告流量词**的分布比例。同时关注“**主要流量词**”和“**有效转化词**”的标签，这些是竞品流量的核心来源。这一步帮你了解竞品的流量布局，找出值得借鉴的词。

#### 第三步：用「出单词反查」验证真实转化
把从「关键词反查」中得到的关键词清单，放到「出单词反查」中验证。**能查出来的词，就是竞品确实靠它出单的词**，转化确定性最高。需要注意的是，出单词反查只收录点击排名前三的ASIN，所以覆盖面较窄，但数据权威性最强。

#### 第四步：落地执行
- **出单词反查验证通过的词** → 高确定性核心词，优先放入手动精准广告；
- **关键词反查发现、但出单词反查未验证的词** → 放入词组或广泛匹配，作为测试词；
- **关键词挖掘得到的词** → 筛选后埋入Listing标题、五点描述和后台搜索词。

### 💡 关键技巧

1. **关键词挖掘的“高频词”功能**：可以快速发现某个细分品类的用户需求热点。
2. **关键词反查的“全部变体拓词”**：如果竞品有多个变体，勾选“全部变体”可以覆盖所有变体的流量词，避免遗漏。
3. **出单词反查的“反查方法”**：如果ASIN属于多变体父Listing，查询时会弹出选项，选择合适的反查方法能获得更精准的数据。
